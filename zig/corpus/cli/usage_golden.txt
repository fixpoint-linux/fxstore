fxstore — content-addressed build store (M0/M1/M2 MVP)
usage:
  fxstore init [dir]                     scaffold a project dir
  fxstore build [--store DIR] [<pkg>...]  build the closure of <pkg>...
                                          (all packages when none), print store paths
  fxstore query <pkg> [--store DIR]      print <pkg>'s closure names + store path
  fxstore gc [<root>] [--retain N] [--store DIR]
                                          prune store dirs/facts unreachable from <root>
                                          (--retain N: keep N most-recent snapshots instead)
  fxstore timeline [--store DIR]         list every snapshot version, marking CURRENT
  fxstore rollback [--hard] <v> [--store DIR]
                                          roll the store back to snapshot version <v>
                                          (default roll-forward; --hard repoints CURRENT)
  fxstore what <target> [--as-of N] [--store DIR]
                                          show the install fact managing <target>
                                          (the provenance proof tree)
  fxstore why <pkg> [--as-of N] [--store DIR]
                                          show why <pkg> is in the store (its closure,
                                          provided targets, pulling roots)
  fxstore verify [<rootfs>] [--as-of N] [--store DIR]
                                          reconcile <rootfs> (default /) against the
                                          recorded install facts; exit 1 on drift
options:
  --store DIR   store root (default: /fx/store)
  --retain N    (gc) keep the N most-recent snapshot versions, prune the rest
  -n N          same as --retain N
  --hard        (rollback) recovery-only: repoint CURRENT directly at <v>, no new version
  --as-of N     (what/why/verify) read snapshot version N instead of the newest published
                (a manual rollback does not re-publish — use --as-of to read the
                rolled-back activation facts)
  -h, --help    show this help
build/query load "package-set.dhall" from the current directory.
